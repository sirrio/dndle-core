# dndle-core

Shared React game shell for [Spelldle](https://sirrio.github.io/spelldle/) and [Critterdle](https://sirrio.github.io/critterdle/).

It provides the daily UTC puzzle selection, six-guess board, comparison results, local statistics, result sharing, responsive layout, tooltips, and legal footer. Each game supplies its own entries, icons, comparison traits, copy, theme, and storage namespace.
